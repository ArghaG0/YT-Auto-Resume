Background Playback & Updates

Browser Sleeping Tabs / Memory Saver

If your browser freezes background tabs (e.g. Edge Sleeping Tabs or Chrome Memory Saver), YouTube tabs may be completely halted. Add youtube.com to your browser's "Never put these sites to sleep" list.

Updating via GitHub Releases

To update YouTube Auto Resume: download the latest release ZIP from GitHub, extract over your local folder, and click the Reload icon on chrome://extensions.

Reset to Defaults

Restores all toggles and configurations to default factory settings.

Privacy Assurance: YouTube Auto Resume runs 100% locally on your machine. No accounts, viewing history, telemetry, or external network requests are made.
